Editorial Framework

The Aspiration Index

Every object we consider is scored on a single axis before it enters the collection. We have never stocked anything below the third mark.

Content
You own a thing. It works. You are not thinking about it.
Curated
You chose the thing. You could name the maker if asked.
Elevated
The thing has a number instead of a name. There is a waiting list.
Insufferable
You now describe the thing unprompted. This is where we operate.

The index is proprietary, unvalidated, and has never been shown to anyone outside the studio.

The Journal

Longform, mostly about mornings

Slow Living

We Let an AI Optimise Slow Living. It Told Us to Go Faster.

We fed four years of morning-routine data into a model and asked it to find the optimum. It recommended waking later, skipping the ritual, and reclaiming ninety minutes. We have not implemented any of this.

The model has been retired. The ritual continues.
